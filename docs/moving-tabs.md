# タブとウィンドウ

タブを左右にドラッグすると、同じウインドウの中で並べ替えられます。複数タブがあるときにタブ列の外へドラッグすると、ボタンを離す前に実際の作業画面を持つ別ウインドウが表示され、ポインターに追従します。ドラッグ中の画面は操作できず、移動元が接続と同期を所有したまま、ボタンを離した時に引き継ぎを確定します。別のNearlyウインドウのタブ列では受け入れ先だけに挿入位置を表示します。Escapeや初期化失敗では元に戻ります。

移動先の準備ができるまで、元のタブの接続と同期を保持します。実行中の同期は同じ接続とジョブを引き継ぎます。移動先の終了や準備失敗では元のタブに戻ります。移動対象の操作や確認画面が進行中の場合は、終了してからドラッグしてください。右クリックの「新しいウィンドウに移動」は廃止しました。

1タブだけのウインドウでは、新しいウインドウを作らず、そのウインドウ自体を動かします。別のウインドウへ結合した場合は、引き継ぎが成功してから空の移動元を閉じます。最後のタブを閉じた場合もそのウインドウを閉じます。別ウインドウの同期は続き、すべてのウインドウを閉じるとアプリが終了します。同期中のタブやウインドウは、同期を停止してから閉じてください。

起動中に Nearly.exe をもう一度起動すると、既存プロセスの中に新しい空のウィンドウが開きます。既存タブの複製、自動接続、自動同期は行いません。最初のウィンドウを閉じた後も、別のウィンドウが残っていれば同じ動作になります。

閉じたタブの復元機能はありません。保存済みの接続先には、最後に正常に閲覧したローカルとリモートの場所を記憶します。ホスト・ポート・ユーザー・接続方式が異なる接続先の履歴は混ざりません。接続は明示的に操作し、場所が見つからなければ選び直せます。

一度同期を開始したタブでは「同期」の右に同じ見た目の「再開」を表示します。「再開」へマウスを重ねるかキーボードでフォーカスすると、前回の同期元と同期先を確認できます。「同期」は現在ローカル側で開いているフォルダーを使い、「再開」は前回の組み合わせと設定で新たに走査します。閲覧先を変えても前回の対象は変わりません。再開の文脈は同じセッション内で保持し、アプリ再起動では復元しません。設定の同じ項目への同時編集は安全側に拒否します。

設定の競合後、再読み込みしても「Settings baseline is ambiguous」が続く場合は、対象ウィンドウの同期を停止してから閉じ、新しいウィンドウで操作してください。異なる保存履歴の競合を安全側で拒否する仕組みは保持しています。

検証の範囲と実機での確認手順は [native-drag-manual-qa.md](native-drag-manual-qa.md) を参照してください。OS の実ポインター操作、複数モニター、混在 DPI は自動検証と区別しています。
