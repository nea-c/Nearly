# タブとウィンドウ

タブを左右にドラッグすると、同じウィンドウの中で並べ替えられます。タブ列から十分離してドラッグすると、タブのプレビューが表示されます。そのまま離すと新しいウィンドウへ移動します。別の Nearly ウィンドウのタブ列に重ねると挿入位置が表示され、そこで離すとその位置へ移動します。Escape で中止できます。

移動先の準備ができるまで、元のタブの接続と同期を保持します。実行中の同期は同じ接続とジョブを引き継ぎます。移動先の終了や準備失敗では元のタブに戻ります。移動対象の操作や確認画面が進行中の場合は、終了してからドラッグしてください。右クリックの「新しいウィンドウに移動」は廃止しました。

最後のタブを移動した場合、元のウィンドウには空のタブが残ります。別ウィンドウの同期は独立して続きます。同期中のウィンドウを閉じるときは、そのウィンドウの同期を停止してください。

起動中に Nearly.exe をもう一度起動すると、既存プロセスの中に新しい空のウィンドウが開きます。既存タブの複製、自動接続、自動同期は行いません。最初のウィンドウを閉じた後も、別のウィンドウが残っていれば同じ動作になります。

アプリをすべて終了して開き直した場合、保存されたタブの同期ルートと設定は復元されます。接続と同期の再開は明示的に操作します。ウィンドウの分け方は保存しません。複数のウィンドウから異なる設定を保存でき、同じ項目の編集が競合した場合は保存エラーを表示します。

設定の競合後、再読み込みしても「Settings baseline is ambiguous」が続く場合は、対象ウィンドウの同期を停止してから閉じ、新しいウィンドウで操作してください。異なる保存履歴の競合を安全側で拒否する仕組みは保持しています。

検証の範囲と実機での確認手順は [native-drag-manual-qa.md](native-drag-manual-qa.md) を参照してください。OS の実ポインター操作、複数モニター、混在 DPI は自動検証と区別しています。
